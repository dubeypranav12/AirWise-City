        About & honest limitations
        
      
          
        
        • AQI uses India's CPCB categories (Good 0-50 ... Severe 401-500). Values are an hourly estimate; official CPCB values use 24-hour/8-hour averages.
          • 
        
        • Live data comes from Open-Meteo (model/analysis based), not ground-sensor readings.
          • 
        
        • The forecast is a Linear Regression trained in Python and run in your browser. See the model note above for its tested error against a "same as now" baseline.
          • 
        
        • "Reasons" are contributing factors, not proven pollution sources. The simulator uses assumed source shares.
          • 
        
        • Health advice is general information, not medical advice.
