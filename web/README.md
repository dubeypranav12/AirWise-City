# AirWise City - website (HTML + CSS + JavaScript)

## Run it (VS Code)
1. Open the `web` folder in VS Code (File > Open Folder).
2. Install the **Live Server** extension (Ritwick Dey).
3. Right-click `index.html` > **Open with Live Server**. (Double-clicking index.html also works.)
4. Top bar: **Demo** works offline. **Live** needs internet (Open-Meteo). Pick a zone from the dropdown.

## Files (read them in this order)
| File | Job |
|---|---|
| `index.html` | page structure |
| `css/style.css` | dark glass design; accent colour follows the AQI |
| `js/aqi.js` | CPCB AQI calculation |
| `js/forecast.js` | features + forecast (Linear Regression, runs in the browser) |
| `js/advice.js` | health advice, authority actions, simulator |
| `js/data.js` | Live (Open-Meteo) -> Cached -> Demo fallback |
| `js/charts.js` | hand-made canvas chart |
| `js/map.js` | Leaflet map (offline fallback plot) |
| `js/app.js` | connects everything |
| `data/*.js` | generated by Python - do not edit |

## Refresh data / model (needs Python, run in the project root)
```
python scripts/fetch_history.py --days 90     # real data
python train_model.py
python scripts/export_web_data.py             # rewrites web/data/*.js
```
The shipped data is SAMPLE data (the page says so). After exporting from real data the label disappears.

## Deploy free
Push the `web` folder to GitHub > Settings > Pages (or drag the folder into Netlify Drop).

## Honest notes
- AQI is an hourly estimate (official CPCB uses 24 h averages). Live data is model-based, not sensors.
- Telegram is not in the browser version: a bot token in front-end code would be public. Needs a tiny backend.
- Live mode and the map were not testable in the build sandbox (no internet) - test them on your PC.
